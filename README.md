# CMD Manager

Менеджер консолей для работы с несколькими проектами в ИИ-агентах на Windows: [Claude Code](https://claude.com/claude-code), Codex (ChatGPT), Gemini CLI, Grok, Kimi Code, Qwen Code, GitHub Copilot CLI, Cursor Agent, OpenCode, MiMo Code, Aider. Все консоли собраны в одном окне. Это удобнее, чем держать десяток окон PowerShell.

*English summary below.*

## Возможности

- **Разные ИИ-агенты.** В каждом проекте выбирается агент и режим: без подтверждений, с подтверждениями, только консоль или своя команда. Есть опция «продолжить прошлый разговор». Программа подсказывает, какие агенты установлены на компьютере, а для SSH-проектов проверяет, какие есть на сервере. Через «Открыть с другим агентом…» в одном проекте можно запустить несколько агентов рядом. Команды и флаги каждого агента можно поменять в настройках («Команды агентов»).
- **Вкладки.** Каждая консоль открывается во вкладке, переключение кликом или по `Ctrl+Tab` / `Ctrl+1…9`.
- **Сетка 1 / 2 / 4 / 6 / 8.** Можно видеть сразу несколько консолей. Вкладку можно перетащить в нужную ячейку, а двойной клик по заголовку разворачивает ячейку на всё окно.
- **«Создать проект».** Программа создаёт папку, открывает в ней PowerShell и запускает `claude --dangerously-skip-permissions`.
- **«Открыть проект».** Можно выбрать папку на компьютере или **сервер по SSH**.
- **Проекты на серверах по SSH.** Сначала подключение: адрес, пользователь и пароль. Программа создаёт ключ `~/.ssh/id_ed25519_<сервер>` (если ключ уже есть, использует его) и один раз устанавливает его на сервер, войдя по паролю. Пароль нигде не сохраняется. Затем открывается обзор папок на сервере, где можно выбрать папку проекта или создать новую. Дальше подключение идёт без пароля, одним кликом.
- **Где запускать Claude для SSH-проекта.** Вариант «на сервере»: Claude запускается на сервере. Вариант «на этом компьютере»: Claude запускается локально (в своей папке, где хранится история разговоров) и сразу получает задание подключиться к серверу по готовой команде `ssh -i ~/.ssh/id_ed25519_<сервер> -o BatchMode=yes user@host` и работать в выбранной папке. Текст задания можно поменять в настройках проекта.
- **Варианты запуска Claude на сервере:** без подтверждений; без подтверждений под root (`IS_SANDBOX=1`, иначе Claude под root отказывается работать с `--dangerously-skip-permissions`); с подтверждениями; только консоль; своя команда. Отдельно можно включить «продолжить прошлый разговор» (`--continue`). Для пользователя root по умолчанию выбирается вариант с `IS_SANDBOX=1`.
- **История проектов.** Достаточно одного клика, чтобы открыть консоль и запустить Claude. Список отсортирован по дате последнего открытия, есть поиск и закрепление проектов.
- **Названия проектов.** Отображаемое имя может отличаться от имени папки.
- **Своя команда запуска** для отдельного проекта, например `claude --continue`.
- **Индикатор работы.** Точка на вкладке пульсирует, пока Claude работает. Когда Claude закончил или ждёт ответа, вкладка подсвечивается, а кнопка на панели задач мигает.
- Сочетание `Shift+Enter` вставляет перевод строки в поле ввода Claude. Копирование и вставка работают через `Ctrl+C` / `Ctrl+V` и правую кнопку мыши.
- При закрытии программы завершаются все запущенные в ней процессы, «висящих» консолей не остаётся.

## Как это устроено

- **C++ / Win32.** Консоли запускаются через [ConPTY](https://learn.microsoft.com/windows/console/creating-a-pseudoconsole-session) (тот же механизм, что в Windows Terminal). Нативная часть также отвечает за окно, диалоги выбора папки, хранение состояния и Job Object, который убирает дочерние процессы при выходе.
- **WebView2 + [xterm.js](https://xtermjs.org/).** Отвечают за отрисовку терминалов, вкладки, сетку и список проектов. xterm.js — это движок терминала из VS Code, поэтому полноэкранный интерфейс Claude Code отображается корректно.

```
src/main.cpp          окно, WebView2, обработка сообщений из интерфейса
src/pty_session.*     одна консоль: ConPTY + процесс + потоки чтения
src/ssh_tools.*       SSH: создание ключа, проверка входа, запуск ssh.exe
src/installer.*       установка, обновление, удаление (один exe)
src/update.*          проверка и загрузка обновлений с GitHub Releases
tools/pack-web.ps1    упаковка web/ внутрь exe
web/                  интерфейс (HTML/CSS/JS) и xterm.js
third_party/          WebView2 SDK, nlohmann/json
```

Данные (список проектов, настройки, положение окна) хранятся в `%APPDATA%\CMDManager`.

## Требования

- Windows 10 1809+ или Windows 11 (нужна поддержка ConPTY)
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (в Windows 11 уже установлен)
- Установленный [Claude Code](https://docs.claude.com/claude-code), команда `claude` должна быть доступна в `PATH`
- Для проектов по SSH: клиент OpenSSH (в Windows 10/11 установлен по умолчанию) и Linux/macOS-сервер с установленным `claude`

## Установка

Скачайте `CMDManager-Setup-vX.Y.Z.exe` со страницы [Releases](https://github.com/yualko/CMDmanager/releases/latest) и запустите его. Это один файл: программа, установщик и средство обновления сразу.

- **«Установить».** Программа ставится в `%LOCALAPPDATA%\Programs\CMDManager`, права администратора не нужны. Появляются ярлык в «Пуске» (по желанию и на рабочем столе) и запись в «Параметры → Приложения», откуда программу можно удалить.
- **«Запустить без установки».** Портативный режим, программа запускается прямо из скачанного файла.
- **Обновления.** При запуске программа проверяет последний релиз на GitHub. Если есть новая версия, в боковой панели появляется кнопка «Обновить»: программа скачает установщик, закроется, обновится и откроется снова. Список проектов и настройки сохраняются. Если запустить новый установщик вручную, он тоже обновит установленную версию.

## Сборка из исходников

Нужна Visual Studio 2022 (или Build Tools) с компонентом **«Разработка классических приложений на C++»**. Все зависимости уже лежат в репозитории.

```bat
build.bat
```

Результат:
- `build\CMDManager.exe` — запускается прямо из репозитория, интерфейс берётся из `web\` (правки видны сразу);
- `dist\CMDManager-Setup-vX.Y.Z.exe` — файл для релиза: интерфейс вшит внутрь, работает как установщик и обновление.

Версия задаётся в `src/version.h`. Релиз: поменять версию, запустить `build.bat`, создать на GitHub релиз с тегом `vX.Y.Z` и приложить exe из `dist\`.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | следующая / предыдущая вкладка |
| `Ctrl+1…9` | перейти к вкладке по номеру |
| `Ctrl+Shift+N` | создать проект |
| `Ctrl+Shift+O` | открыть проект |
| `Ctrl+Shift+W` | закрыть консоль |
| `Ctrl+Shift+Enter` | развернуть консоль / вернуть сетку |
| `Ctrl+Shift+B` | показать / скрыть список проектов |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0`, `Ctrl+колесо` | размер шрифта |
| `Shift+Enter` | новая строка в Claude Code |
| `Ctrl+C` при выделении, правый клик | копировать / вставить |

## Отладка

- `set CMDM_DEVTOOLS=1` — включает DevTools (F12) и контекстное меню WebView2.
- `set CMDM_DATA_DIR=путь` — использовать отдельную папку данных, например для тестов.

## ⚠️ О флаге `--dangerously-skip-permissions`

По умолчанию Claude запускается с флагом `--dangerously-skip-permissions`. В этом режиме Claude выполняет команды и меняет файлы без подтверждения. Команду запуска можно поменять в **Настройках** (для всех проектов) или в свойствах отдельного проекта.

## English summary

CMD Manager is a small Windows app (C++/Win32 + ConPTY + WebView2 + xterm.js) that gathers all your Claude Code consoles in one window. It provides tabs, a 1/2/4/6/8 split grid, one-click "create/open project" that starts PowerShell in the folder and runs `claude --dangerously-skip-permissions`, a named project history, and activity/attention indicators. To build, run `build.bat` with Visual Studio 2022 (C++ workload) installed.
